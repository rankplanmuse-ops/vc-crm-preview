# VC Base - UI preview

Static snapshot of the VC Base (PE/VC prospect CRM) user interface, rendered
from sample data with the app's preview mode (VC_MOCK). Published via GitHub
Pages: https://rankplanmuse-ops.github.io/vc-crm-preview/

This is a look-and-feel preview only. The live app (private repo
rankplanmuse-ops/vc-crm) runs on Next.js + Supabase with real data, a working
AI crawl pipeline and review-before-filing; forms in this snapshot are
illustrative and do not submit anywhere.
